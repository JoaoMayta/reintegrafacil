# Identidade visual ReintegraFacil

Arquivo principal: reintegrafacil.svg. Todos os cabeçalhos e rodapés que apresentam a marca usam este mesmo arquivo. Não criar versões da marca em HTML ou recolorir por CSS. O logo possui uma base branca, símbolo preto e amarelo e nome preto para manter as mesmas cores em fundos claros e escuros. Tamanhos responsivos são definidos somente em marca.css; manter proporção340:88 e texto alternativo ReintegraFacil.

O favicon é o recorte do mesmo símbolo, sem um desenho alternativo. Tipografia do logo: Barlow Condensed Bold, convertida em curvas a partir do arquivo local sob SIL Open Font License1.1. A licença original está em /assets/fonts/BarlowCondensed-OFL.txt. Desenho do símbolo e composição criados para este projeto em08/11/2026. Não contém dados pessoais ou recursos externos.
